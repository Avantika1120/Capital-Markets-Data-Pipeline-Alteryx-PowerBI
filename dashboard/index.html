About this dashboard

This HTML file is a recruiter-facing companion to the Power BI report. It is intentionally data-driven: upload the generated daily table and the page recalculates the latest security snapshot, cumulative-return lines, and risk/return scatter directly in the browser.

The production portfolio artifact remains the Alteryx workflow plus Power BI report once those desktop files have been created and executed.
